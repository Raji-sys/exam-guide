Suspension — definition
When a prima facie case of criminal offence is established against an officer and it is in public interest, the officer ceases to perform duties and salary is stopped until the disciplinary committee gives final judgment. If found not guilty, salary arrears are fully paid.

Transfer vs posting vs secondment trick question
Transfer: PERMANENT release of officer from one service to another within the same service. Not for a specific period.

Posting: TEMPORARY deployment of officer from one office to another or from one ministry to another.

Secondment: Temporary release of officer to the services of ANOTHER government or agency for a specific period.

Misconduct: A willful act or improper behavior which can be investigated.

13. Steps — clearing DNS cache on Windows
1Click Start menu → type CMD in search bar
2Right-click Command Prompt → Run as Administrator (required)
3Type exactly: ipconfig /flushdns
4Press Enter
5Confirmation message: "Successfully flushed the DNS Resolver Cache" appears
Note: Applies to Windows 8, 10, and 11. Requires admin rights or it will fail.
14. Steps — computer refuses to boot
1Check power supply — confirm cable is properly plugged in and outlet works
2Listen for beep codes — BIOS beep patterns identify specific hardware faults
3Boot in Safe Mode — Win 10/11: hold Shift + Restart → Troubleshoot → Advanced → Startup Settings
4Check hardware — reseat RAM sticks, hard drive connectors, GPU
5Use Startup Repair — boot from Windows USB/DVD → Repair your computer
15. Steps — system cannot connect to internet
1Isolate the problem — is it one device or all? One device = local issue
2Check physical connections — LAN cable plugged in? Wi-Fi on and connected?
3Restart router and modem — unplug, wait 30 seconds, plug back in
4Run Network Troubleshooter — Settings → Network & Internet → Troubleshoot
5Check IP/DNS settings — ensure set to obtain address automatically (DHCP)
6Flush DNS & reset TCP/IP — CMD as Admin: ipconfig /flushdns then netsh int ip reset
